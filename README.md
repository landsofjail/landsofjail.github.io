## 📖 What is this?

This site is a community-built reference site covering heroes, events, and upgrade systems for *Lands of Jail*, along with a set of interactive calculators for planning formations and countering enemy line-ups.

It is a **fan project**, not affiliated with or endorsed by the game's developer or publisher.

## 🗺️ Site Map

When you land on `home.html`, a welcome pop-up lets you jump straight to any of the following sections:

| Section | What's inside |
|---|---|
| 🏠 **Main Page** (`index.html`) | The full hero database and index of every guide page |
| 🎪 **Event Guide** | The Cage Event walkthrough |
| ⚔️ **Battle Guide** | The Ultimate Warfare Guide and the Troop Guide (troop triangle, combat mechanics) |
| ⬆️ **Upgrading Guide** | Tome, Trove, Prisoner Armor, Hero Star, and Hero Equipment upgrade requirements |
| 🛠️ **Tactical Toolkit** | Three interactive calculators (see below) |

## 🛠️ Interactive Tools

- **Tactical Formation Calculator** — pick a battle mode and scout the enemy for an instant formation, robot pick, and troop ratio.
- **Enemy Counter Analyzer** — report the enemy's hero lineup and Power Armor to get a scout report and a matching counter formation.
- **Arena Counter Analyzer** — report the enemy's 5-Hero Arena lineup and Power Armors for a Shield/Bomber/Shooter counter build, based on each Hero's real Arrest stats and skills.
