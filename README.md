# Lands of Jail Heroes Hub — v2

Free static website prototype for GitHub Pages.

## Main features
- English hero names
- Search
- Rarity filters (SSR / SR / R)
- Role filters (Shield / Shooter / Rider)
- Season filters (S-1 ... S-6)
- Sorting
- Hero detail modal
- Editable `heroes.json`
- Responsive desktop/mobile layout

## Editing data
Open `heroes.json` and update the fields for each hero:
`description`, `skills`, `warSkill`, `equipment`, `bestTeams`, and `notes`.

The visual design and functionality are separated from the data, so adding information does not require redesigning the page.
