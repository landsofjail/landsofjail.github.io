## 📖 이 사이트는 무엇인가요?

이 사이트는 *Lands of Jail*의 영웅, 이벤트, 업그레이드 시스템을 다루는 커뮤니티 제작 참고 사이트이며, 편성 계획과 적 편성 카운터를 위한 인터랙티브 계산기들을 함께 제공합니다.

이 사이트는 **팬 프로젝트**이며, 게임 개발사 또는 배급사와 아무런 관련이 없습니다.

## 🗺️ 사이트맵

`home.html`에 접속하면 나타나는 환영 팝업을 통해 아래 섹션으로 바로 이동할 수 있습니다:

| 섹션 | 포함된 내용 |
|---|---|
| 🏠 **메인 페이지** (`index.html`) | 전체 영웅 데이터베이스와 모든 가이드 페이지 목록 |
| 🎪 **이벤트 가이드** | Cage 이벤트 공략 |
| ⚔️ **전투 가이드** | 얼티밋 워페어 가이드와 병종 가이드(병종 삼각관계, 전투 메커니즘) |
| ⬆️ **업그레이드 가이드** | 토므, 트로브, 프리즈너 아머, 영웅 별, 영웅 전용 장비 업그레이드 요구사항 |
| 🛠️ **전술 도구 모음** | 아래에 소개된 3가지 인터랙티브 계산기 |

## 🛠️ 인터랙티브 도구

- **전술 편성 계산기** — 전투 모드를 선택하고 적을 정찰하면 즉시 편성, 로봇 선택, 병력 비율을 알려줍니다.
- **적 카운터 분석기** — 적의 영웅 편성과 파워 아머를 입력하면 정찰 보고서와 그에 맞는 카운터 편성을 제공합니다.
- **아레나 카운터 분석기** — 적의 5인 아레나 편성과 파워 아머를 입력하면, 각 영웅의 실제 체포(Arrest) 스탯과 스킬을 기반으로 실드/폭파범/슈터 카운터 편성을 제공합니다.

## ⚠️ 안내

이 사이트는 비공식 팬 제작 커뮤니티 자료입니다. 모든 게임 자산, 명칭, 상표권은 각 소유자에게 있습니다. 인터랙티브 도구에 표시되는 수치는 공개된 스킬 및 장비 데이터를 기반으로 한 단순화된 추정치이므로, 자원을 투입하기 전에 반드시 실제 게임 내 수치를 확인하시기 바랍니다.
