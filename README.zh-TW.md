## 📖 這是什麼網站？

本站是由社群製作的《Lands of Jail》參考網站，涵蓋英雄、活動與升級系統的攻略，並提供一系列互動計算工具，協助規劃編成與反制敵方陣容。

本站為**粉絲專案**，與遊戲開發商或發行商並無任何關聯。

## 🗺️ 網站地圖

進入 `home.html` 時，歡迎彈出視窗會讓你直接前往以下任一區塊：

| 區塊 | 內容 |
|---|---|
| 🏠 **主頁** (`index.html`) | 完整的英雄資料庫與所有攻略頁面索引 |
| 🎪 **活動指南** | Cage 活動完整攻略 |
| ⚔️ **戰鬥指南** | 終極戰爭指南與部隊指南（部隊三角關係、戰鬥機制） |
| ⬆️ **升級指南** | 典籍、寶庫、囚犯裝甲、英雄星級與英雄專屬裝備的升級需求 |
| 🛠️ **戰術工具包** | 下方介紹的三款互動計算工具 |

## 🛠️ 互動工具

- **戰術編成計算機** — 選擇你的戰鬥模式並偵查敵方，立即獲得編成建議、機甲選擇與部隊比例。
- **敵方反制分析器** — 回報敵方的英雄編成與動力裝甲，取得偵查報告與對應的反制編成。
- **競技場反制分析器** — 回報敵方的 5 位競技場英雄編成與動力裝甲，系統將根據每位英雄真實的緝捕（Arrest）屬性與技能，提供護盾／爆破手／射手反制編成建議。
